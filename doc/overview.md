# Welcome to eQ

eQ is a simple and secure tool that helps you generate private keys and wallets for 285 different cryptocurrencies.

It was built to be fast, reliable, and privacy-focused. Everything happens on your own computer — no internet is required for key generation, except when you want to use QRNG.

### Why use eQ?
- Extremely fast key generation
- Strong security defaults (everything sensitive is properly cleared from memory)
- Optional quantum-grade randomness from real physics (ANU QRNG)
- Wallets are saved as encrypted SVG image files
- Supports BIP39 mnemonics, passphrases, and all major derivation standards

Whether you are new to crypto or an experienced user, eQ makes creating safe wallets straightforward.

Just open the app, choose your options, and generate.
