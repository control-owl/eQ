# Coins

This section documents native blockchain coins, their current status, supported address formats, derivation paths, and historical notes.

## Status legend

| Status | Meaning |
|---------|---------|
| Active | Network is active and maintained |
| Legacy | Older address format kept for compatibility |
| Deprecated | Supported but not recommended for new wallets |
| Rebranded | Coin changed its name or ticker |
| Migrated | Assets moved to another blockchain |
| End of life | Network is no longer maintained |
